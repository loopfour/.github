## About JustPaid

JustPaid is an autonomous AI billing platform for B2B companies. We handle everything from contract extraction to invoice generation, payment collection, and reconciliation — so finance teams can stop chasing invoices and focus on what matters.

This GitHub organization is where we publish **practical open-source tools** for finance teams, developers, accountants, and AI agent builders working with financial workflows.

---

## What We're Building (Open Source)

We're starting with small, useful building blocks — not large abstract frameworks.

| Category | What it does |
|:--|:--|
| **SDKs** | Client libraries for the JustPaid API |
| **Agent Skills** | Composable skills for AI agents performing finance operations |
| **Automation Examples** | Reference workflows for billing, collections, reconciliation, and reporting |
| **Integrations** | Connectors for Stripe, QuickBooks, Xero, Salesforce, and more |
| **Utilities** | Tools that make financial operations easier to inspect, script, and extend |

Our goal: make finance work more **programmable**, **auditable**, and **agent-friendly**.

## Projects

### `justpaid-python-sdk`
Python SDK for the JustPaid API. Connect internal tools, scripts, and automation workflows to JustPaid.

### `justpaid-openclaw-skill`
An agent skill for finance workflows — billing, collections, and reporting tasks designed for AI agents to perform safely and consistently.

> More tools are coming as we open up reusable pieces from our internal finance automation stack.

## Who This Is For

- **Finance teams** — repeatable automation instead of spreadsheet-heavy manual work
- **Founders & operators** — clearer visibility into cash flow, receivables, and revenue
- **Accountants, controllers & RevOps** — better day-to-day workflows and reporting
- **Developers** — finance integrations, internal tools, and back-office automation
- **Agent builders** — reliable skills and examples for AI-powered finance operations

---

## Our Principles

```
 Clear         → Finance teams can trust what the tool does
 Simple        → No long setup process, works out of the box
 Explicit      → Inputs, outputs, and side effects are always visible
 Practical     → Built for real workflows, not just demos
 Safe          → Designed for sensitive financial operations
```

Finance automation should not be magic. It should be legible, testable, and dependable.

## Contributing

We're early in opening this ecosystem. Contribution guidelines will expand as projects mature.

**For now:**

1. Open an **issue** for bugs or concrete workflow requests
2. Submit **pull requests** for small, focused improvements
3. Include **clear examples** when proposing new finance skills or patterns
4. Never submit code that logs, exposes, or assumes access to sensitive financial data

If you're building finance automations, agent skills, or integrations — we'd love to see what you're working on.

---

## Security

Financial systems handle sensitive data. **Do not open public issues** for security vulnerabilities or anything involving private customer, payment, invoice, or account data.

For security concerns, reach out to **[support@justpaid.io](mailto:support@justpaid.io)**.
