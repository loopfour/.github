# Loopfour

Loopfour Inc. builds, runs and maintains finance workflows as deterministic, auditable code on the systems finance teams already use, including NetSuite, QuickBooks, Stripe and Salesforce. Loopfour also makes JustPaid, its billing product. Y Combinator W23. Remote-first team in the San Francisco Bay Area. +1 (650) 800-8163.
