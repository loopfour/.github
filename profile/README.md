## About JustPaid

JustPaid is an **autonomous AI billing platform** that handles everything from contract extraction to invoice generation, payment collection, and reconciliation — so B2B finance teams can stop doing manual work and focus on what matters.

We bring clarity to your finances — from spend management to payments to real-time analytics — all in one system built for speed and scale.

---

---

## What We Do

| Capability | Description |
|:--|:--|
| **Automated Invoicing** | Create, send, and track invoices with custom pricing models and scheduled billing cycles |
| **Collections on Autopilot** | AI-powered payment reminders and escalation sequences that adapt to customer behavior |
| **AI Contract Extraction** | Upload contracts — AI extracts billing terms, payment schedules, and line items |
| **Payment Reconciliation** | Automatically match payments from Stripe, banks, and accounting software to invoices |
| **Revenue & Cash Flow** | Real-time dashboards for collected vs. outstanding payments, trends, and gaps |
| **Multi-Currency Billing** | Bill customers in their preferred currency with automatic conversion |

## Contributing

We're early in opening this ecosystem and will expand contribution guidelines as projects mature.

1. Open an **issue** for bugs or concrete workflow requests
2. Submit **pull requests** for small, focused improvements
3. Include **clear examples** when proposing new finance skills or patterns
4. Never submit code that logs, exposes, or assumes access to sensitive financial data

---

## Security

Financial systems handle sensitive data. **Do not open public issues** for security vulnerabilities or anything involving private customer, payment, invoice, or account data.

For security concerns, reach out to **[support@justpaid.ai](mailto:support@justpaid.ai)**.
